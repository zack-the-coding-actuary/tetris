# Tetris

I made a basic Tetris game to start learning 2D game development using the raylib library. The code is spaghetti but the vibes are there. No wall / floor kicking or fancy mechanics like that.

# Controls

- **Left / Right arrow keys** - Move piece left / right
- **Up arrow key** - Rotate piece
- **Down arrow key** - Move piece down one time
- **Spacebar** - Move piece down quickly
